# Plataforma de gestión de notas y organización personal

Proyecto personal en desarrollo, inspirado en herramientas de productividad como Notion y desarrollado en PHP. Busca permitir la creación, organización y gestión de información mediante un sistema de notas y espacios personalizados. Actualmente se encuentra en proceso de finalización, aplicando conceptos de desarrollo web, manejo de datos y diseño de interfaces para construir una experiencia flexible y funcional.
